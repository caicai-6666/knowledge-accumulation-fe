# 界面语言

桌面端工作台右上角的日月开关位于用户组件左侧；移动端在左侧问答列表底部省略号打开的设置中切换。开关左侧 `zh` 为中文，右侧 `en` 为英文。默认中文，选择保存到浏览器同源 `localStorage` 的 `knowledge-accumulation.language`；刷新后恢复。存储被禁用或内容无效时回退中文，仍可切换当前界面。

## 翻译范围

前端自带的品牌、导航、按钮、菜单、提示、占位文字、可访问性标签、树图状态、处理用时和前端校验/错误信息均提供英文版本。英文按产品语境编写，例如 AI assistant、Start a new exploration、Open platform，并处理任务、分支和附件数量的单复数。英文欢迎页使用独立的单线字形路径生成探索文案与时段问候，配合英文引导语；选择和轮播规则见[智能体问答](../features/assistant.md#页面与上下文)。

后端平台名称、Markdown 摘要、管理员姓名、问答树名称、历史问题、模型回答、中间输出、公开进度消息和后端错误详情保持原文。公开进度的原始数据不改写；展示层对 `thinking` 使用本地化的固定标签，并按任务终态格式化工具通知，规则见[回答、耗时与处理过程](../features/assistant.md#回答耗时与处理过程)。这不是对后端内容做全局翻译。用户输入及已有文件名同样不翻译。自动生成的图片粘贴文件名和仅含附件时的默认问题按提交时语言生成，此后作为历史内容保留，不随界面切换改写。

## 切换与状态

切换会即时更新前端文字、网页标题和文档 `lang`，不刷新页面、不重建 KeepAlive 容器、不重新登录或重发任务。草稿、附件、当前树、所选节点、队列和原始事件数据均保留。此前显示的前端错误保留来源，可随语言更新；后端原始消息不套用词典。

单棵删除确认语中文为“我确认删除”加完整树名，英文为“Delete ”加完整树名，二者始终使用未翻译的后端树名。弹窗中切换语言会清空旧确认输入，仍需逐字匹配当前提示，不影响已提交的删除请求。多选删除使用数量与范围确认，不输入逐棵确认语，见[移动端多选与置顶](../features/assistant.md#移动端多选与置顶)。

## 代码约定

`src/i18n/en.js` 保存英文词典，中文固定文案作为键。`t` 负责响应式展示及参数插值，不递归处理插入的用户或后端文字。服务端参数、枚举及接口路径不参与翻译。

前端错误通过 `uiText` 标记来源，`LocalizedError` 与 `localizedRef` 保留这种来源并在展示时解析。来自接口的原始字符串直接保留，不能因其恰好与某条前端文案相同而翻译。图标和手写动画继续遵守 KeepAlive、后台暂停和减少动画约定，无额外国际化依赖。
