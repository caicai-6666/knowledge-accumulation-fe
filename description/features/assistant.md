# 智能体问答与问答树

问答页面对接 `knowledge-accumulation-be` 的 exploration 和 resource 路由，使用当前登录用户的中央 token。页面不再加载示例树或生成 mock 回答。接口权威契约见后端的[探索树](../../../knowledge-accumulation-be/description/api/exploration.md)及[资源](../../../knowledge-accumulation-be/description/api/resource.md)文档。

## 页面与上下文

左侧为问答，右侧为树状任务图，分隔柄支持拖动、键盘微调和双击恢复默认宽度。桌面问答宽度按像素保存在当前浏览器 localStorage，拖动结束或键盘调整后保存，刷新或重新进入时恢复；窗口缩小时按问答至少 360px、树图至少 340px 限制显示，恢复宽窗口后仍使用原偏好，移动端不改写该记录。双击分隔柄清除记录并恢复默认比例；存储不可用时仍可调整当前工作台。树图只允许按住空白拖动平移，滚轮不改变缩放；右下控件支持 10%–200% 缩放。节点旁可折叠后代，也可全部展开。桌面与移动端从根到当前任务的全部上下文节点统一使用靛粉液态流动背景，当前节点以较深边框和光晕区分；非上下文节点保留常规背景，离开页面时暂停动画，减少动画偏好下静态展示。

桌面顶部“问答树选择”和下拉框并排，展开后再次点击选择框收起菜单；移动端列表置于左侧抽屉。进入问答页后不在顶部展示列表、记录的加载 hint 或后台刷新提示；请求状态仍用于禁用冲突操作，实际业务请求失败保留错误和重试。身份重新确认后的目录与记录刷新静默进行，不触发前台加载提示；进入应用时的“正在进入”卡片保持原样。列表先读取树的 ID、名称与最后更新时间，选中后请求完整树，优先恢复该用户在当前浏览器上最后选中的任务节点及其上下文路径，没有有效记录时定位有效主干末尾；只有已加载的树显示任务数与分支数。点击任务节点保留根到该节点的上下文。阅读位置按 userid 隔离保存在 localStorage，最多记录 200 棵树，仅保存树和任务 ID；切换树、新建探索或刷新页面后仍可恢复，关键词搜索定位的任务也会成为新的阅读位置。已删除、已替代或变为摘要的记录不恢复；实际打开失败时保留原记录，真实删除或成功目录确认树已移除后清理。存储受限时仅在本次工作台内存中记住位置，不影响真实树加载。服务端摘要节点保留在拓扑与连线中，用虚线卡片区分，不作为用户提问入口，也不重复显示为一轮对话。

桌面问答区域右上角提供字号缩小、放大与当前字号显示，移动端在左侧列表底部设置面板中调整；范围 12–20px，默认 13px；点击中间数值恢复默认。字号仅应用于会话历史中的问题、回答及中间过程正文，不改变输入框、树图和工具栏等其他区域的字号。偏好保存于当前浏览器同源 localStorage，刷新或下次访问恢复；存储不可用时仍可在当前页面调整。

“开始新探索”为常驻选项，采用 `exploration.webp` 图标及与 contract-service-fe 一致的手写欢迎动画。首问发送时创建树，创建请求使用空对象，由后端按北京时间命名；创建成功但任务登记失败时保留空树和草稿，重试继续使用该树。

英文手写欢迎语提供 10 条探索文案与 3 条时段问候，使用独立单线字形路径逐笔书写，沿用渐变、停留与淡出轮播。仅选取当前时段的问候；900px 及以下优先使用不超过 14 个字符的短句。中英文分别记住上一条，连续轮换不重复，存储受限时同一组件仍避免立即重复。切换语言立即选择对应文案并重启书写；后台、缓存停用和减少动画偏好沿用原有暂停规则。

中间过程正文直接渲染 Markdown，不额外显示“过程输出”标签、圆点或脉冲标识，保留展开/收起与时间展示；工具动作仍显示各自状态及图标。

公开过程接受 `thinking`、`online-search`、`external-expert`、`local-search`、`boardcast`、`a2a` 六类后端状态，实时 SSE、任务快照与树历史采用相同类型范围。`boardcast` 表示跨平台广播求助，保留后端约定的实际拼写；`a2a` 表示跨平台续聊，兼容已有历史事件。分别使用 `boardcast.webp` 和 `a2a.webp` 图标，展示、相邻去重和终态规则与其他工具通知一致。`thinking` 的可见文字统一为“正在思考”（英文 Thinking），不展示该类型后端 message 的具体动作；仅改展示文案，原始事件与过程记录不变。本地文件检索使用 `local-search.webp` 图标，结束文案和展示去重沿用现有过程规则。新增合法工具状态必须同步前端历史校验与展示，避免将含合法事件的整棵树判定为数据不完整。

## 重命名与删除

桌面下拉菜单每棵树的右侧提供编辑和删除图标，悬停或键盘聚焦时显现。移动端不显示行尾编辑和删除按钮，首个分组标题右侧提供[多选入口](#移动端多选与置顶)；长按会话 500ms 打开重命名和删除浮层，突出当前会话并柔化背景，点击外部或按 Escape 关闭。移动超过 10px、列表滚动、指针离开或取消时停止长按计时；长按后的松手不切换会话。键盘 ContextMenu 或 Shift + F10 同样打开操作菜单。关闭抽屉、切换布局或停用页面清理计时器和浮层。重命名使用行内输入，移动端点击改名及切换输入焦点时保持菜单展开，仅 Enter 或勾选按钮保存；失焦保留编辑且不提交，Escape 取消，点击外部或收起菜单取消未保存修改；名称 trim 后为 1–200 个字符。改名、删除在接口确认成功后显示短暂 toast；失败保留原有编辑或确认框并显示错误 toast，删除错误提示位于原生弹窗内，避免被遮挡。成功采用浅绿圆底对勾，错误采用珊瑚红圆底叉号，搭配柔和圆角、阴影和淡入淡出。成功提示约 3 秒、错误提示约 4.5 秒，新结果替换旧提示，离开页面清理提示与计时器；PC、移动端和中英文共用该行为。调用 PATCH name 成功后更新标题，不切换阅读节点，不改变历史与草稿；失败保留输入并在行内提示。

单棵删除沿用参考项目的插图确认弹窗，必须输入“我确认删除”与完整树名，明确告知树、任务及附件将永久删除。只有 DELETE 返回 204 才移除本地记录；失败保留弹窗及记录，可手动重试。删除成功后取消该树订阅，清理草稿、队列与附件 Blob 缓存；删除当前树回到“开始新探索”，删除其他树保留当前阅读位置。请求期间禁用冲突操作，迟到的历史响应不能恢复已删除树。关闭/切页时释放弹窗顶层状态，重试不自动重复删除。

## 提交与模式

Enter 换行，Shift + Enter 发送；输入法组字期间不触发发送。推理强度为 low、medium、xhigh，选择即时保存在同源 localStorage 的 `knowledge-accumulation.assistant.reasoning-effort` 中，刷新或重新进入后恢复；无有效记录时默认 medium，存储受限仍可正常切换和发送。该偏好按浏览器保存，不依赖问答树或界面语言，位于发送按钮左侧；靛粉液态背景随选项滑动。选项与滑块共用宽度，液态动画在独立圆角表面内裁切，保持窄屏上的对齐与边界。强度作为 `thinking_effort` 提交，每轮独立捕获。

推理强度左侧是推进/探索开关，文字在开关左侧。太阳表示推进，月亮表示探索，默认探索。文字和开关整体禁用触摸高亮与文本选择，键盘操作保留可见焦点。只有当前主干末尾的已结束任务可开启推进；切换树或节点自动关闭。推进提交 `mode=main`，其他历史任务和分支提交 `mode=branch`；从主干末尾探索也会创建分支，不自动延伸主干。空树首问固定显示太阳/推进模式且不可切换，提交强制使用 main；选择新探索或编辑草稿均不创建树，只有发送首条消息才创建。

900px 及以下采用左侧问答列表、中间当前问答、右侧问答树的布局，两侧默认收起。顶部左侧保留 logo，右上角胶囊内依次放置关机样式退出按钮和问答树图标，两者垂直居中并用细线分隔；不显示新探索或已选问答树的标题提示。点击 logo 从左侧展开列表，点击右侧树图按钮展开问答树。列表和问答树固定在底层背景中，底色铺满整个可视视口，内容列保持抽屉宽度；会话区域始终是带圆角和柔和阴影的上层工作台。工作台外框延伸到视口上下边缘，安全区留白放在内部内容，避免圆角外露出未铺满的背景缝隙；问答输入框保持悬浮，距底边 16px（短视口为 10px）；底部安全区由输入框内部 padding 承载，不在输入框下方叠加整段安全区留白。同一时间只显露一侧，打开时将会话工作台整体向另一侧推移并以底边为基点轻微缩小至 97%，底部保持贴边，底层内容不随动；显露宽度为工作台的 82%、最多 380px，保留部分主区域。返回时立即隐藏底层列表或树图内容，底色保留到工作台滑回并恢复原尺寸，避免文字透过半透明工作台；圆角和阴影全程保持，返回遮罩随工作台移动并在其圆角内裁切；点击这部分主区域、关闭按钮或按 Escape 返回问答。抽屉打开后主区域暂停交互，键盘焦点限定在当前抽屉内，关闭后恢复触发按钮焦点；切换至桌面或离开页面关闭抽屉。

移动工作台左边缘 24px 内的单指右滑用于呼出左侧列表，向右至少滑动 48px 且以横向为主时打开；短触、纵向移动、反向、多指或取消手势不打开。边缘手势在触摸起点取消可取消的默认行为；输入控件、按钮、已打开的抽屉及原生弹窗不参与识别，列表打开后，在列表空白处或会话条目上单指向左滑动至少 48px、以横向为主时收起列表并返回问答；轻触、纵向滚动和长按操作保持原行为，完成滑动后的合成 click 被消费，不误选会话。页面停用时移除监听。钉钉移动端工作台尝试通过 SDK 的 `popGesture` 与 `setGestures` 分别关闭容器侧滑退出和 WebView 历史回退，离开工作台或切回桌面时串行恢复；失败不阻塞页面，原生效果需对应客户端验证。普通浏览器的系统级返回仍受浏览器自身限制，不通过重复压入历史记录拦截返回。

关机按钮只关闭当前应用页面，不注销或删除凭据。钉钉调用 `closePage`；普通浏览器有历史时返回上一页，否则尝试关闭标签页。自动关闭不可用时给出提示，交由客户端或浏览器关闭。

移动端工作台占满可视视口并避开安全区域，顶部显示品牌与退出、树图操作；左侧列表使用半透明浅色底面、单行文字条目与宽松间距，底部固定头像和姓名，账户区通过渐变玻璃层与滚动内容衔接。顶部提供缓存对话关键词搜索和新探索按钮，搜索范围与定位规则见下方“对话关键词搜索”；列表按服务端 `updated_at` 倒序，转换为浏览器本地日历日期分组：今天、昨天、7天内（距今天 2–6 天）、30天内（7–29 天），30 天及更早按“YYYY年M月”归组。仅显示有记录的分组，搜索后保持相同规则，跨本地午夜及重新激活时刷新分组。创建接口尚未返回时间的新树暂列“其他对话”，收到目录或打开接口的真实时间后归组，不从名称或节点时间推断。生成和未读状态保留，重命名与删除通过长按会话打开操作菜单；清空搜索恢复完整目录。设置对话框仅在首次点击底部省略号时创建，关闭后保持隐藏，不参与首屏挂载。底部省略号通过原生 dialog 模态层打开设置，设置面板从屏幕底部滑出，主体左右收窄，靠近底部以弧形外扩形成“凸”形轮廓并贴合屏幕底边；顶部保留圆角，内容避开底部安全区域；关闭时向下收回后释放模态层，减少动画偏好下立即切换。语言和问答字号控件直接挂载在模态层内，避免被底层工作台或返回遮罩拦截。圆形 SVG 关闭按钮、点击面板外部或 Escape 可关闭设置并返回省略号焦点，列表仍保持展开。列表独立滚动并延伸到整个底部账户区后方，在账户区上缘开始通过渐变遮罩淡出，同时叠加玻璃模糊；不支持背景模糊时仍保留文字羽化。头像、姓名和设置按钮固定在清晰前景，列表底部留白保证最后一项能滚到羽化区上方完整显示。列表到顶后继续单指下拉，由 12 根短棒组成的环形 loading 随下拉显现，拉动越多、依次变深的短棒越多，手指回推时逐根恢复浅色；达到 64px 的阻尼下拉距离、12 根短棒全部变深时立即刷新，无需松手；拉满前回推会逐根变浅，未达到阈值松手则收回。刷新期间短棒按顺序循环明暗，loading 至少展示 1 秒且等待请求完成后才平滑回弹收起；最短展示计时与请求并行，慢请求不会额外再等 1 秒，关闭列表或离开页面立即清理等待；失败保留原目录并显示局部重试入口；已有目录查询进行时复用该请求，避免重复查询。下拉识别取消长按计时，消耗松手后的 click，不误选会话；横向滑动仍交给左滑收起，关闭列表或停用页面清理手势，不自动重放任何问答或修改请求。选择或新建探索后返回问答，再次点击当前探索也关闭抽屉。问答树选择项和关键词检索结果在点击、焦点移动及已选中状态下均保持透明底色，保留按压回弹与键盘焦点轮廓。列表复用桌面选择组件，切换布局不重建业务会话、草稿或附件。

右侧复用桌面同一树图组件，树图底色由抽屉外层全高承载，覆盖上下安全区，内部组件不重复叠加底色；不展示底部控件，使用独立画布位移，不受原生滚动边界限制；支持从节点或空白处单指自由平移及松手后的惯性减速、双指围绕手势中心缩放（10%–200%），也可同时平移；双指松开一指后接续拖动，再次触摸立即停止惯性，关闭抽屉清理手势与动画；手势不会误触节点。轻触节点后关闭抽屉并切换上下文。减少动画偏好下关闭抽屉推移动画。

移动端禁止整页双击与双指缩放，保留内容滚动以及问答树、附件预览容器内自定义缩放。问答、改名和删除确认输入字号保持 16px，关闭文字自动放大；工作台随可视视口及安全区域调整高度，键盘动画的视口事件按帧合并，工具区在短视口下收紧。程序聚焦不主动滚动整页。中文输入法组字回车不保存改名、不发送问答；问答键盘回车保持换行，发送使用按钮或 Shift + Enter。

注册任务通过 multipart 提交问题、模式、强度、所选任务及 PDF 文件，成功后使用返回的 turn ID 订阅 SSE。任务 ID 与树节点 ID 相同。问题不为空且最多 20000 个字符；每轮最多 10 份 PDF，单份 10 MiB、合计 20 MiB。服务端仍执行最终权限与业务校验。

## 定位与流式追随

沿用 contract-service-fe 的 `messageScrollFollower`：新任务提交成功且成为当前阅读任务后，将该轮用户消息（含上方附件）定位到问答区域顶部，并在下面预留一屏高度。答案先填充预留区域，超出视口后才随实际渲染高度追随末尾，不在每次正文更新时强制跳底。

用户上滚、触摸向下拖动或使用向上翻页键时立即暂停追随；自行回到底部后恢复。排队但尚未发出的消息不改变当前阅读位置。选择历史任务时定位该轮顶部并保持阅读模式；展开处理过程暂时冻结滚动，保留原追随状态。状态切换采用缓动，正文根据实际布局高度追随；调整左右宽度、Markdown 换行及附件渲染引起的高度变化均由观察器处理。

KeepAlive 停用时暂停观察器与动画帧，保留当前位置和追随模式；返回后恢复，销毁时移除监听、占位与计时器。

移动端附件预览使用按需加载的本地 PDF.js 与 Worker 渲染，直接读取已鉴权取得的 Blob，不向外部阅读器上传附件，不依赖浏览器内嵌 PDF 的 load 事件。首屏画布绘制完成后结束加载，多页文件按纸张顺序连续滚动，顶部显示当前位置；支持 100%–300% 的按钮与双指缩放，放大后可在预览内平移，保持手势中心所指内容的位置。页面按可见范围绘制，远离视口的画布会释放，并限制每页像素数和最长边。移动弹窗上下至少留出 24px，兼顾安全区域与悬浮阴影。关闭、切换附件时取消请求和绘制并释放文档；解析或绘制超时显示错误，避免无限加载。桌面保留原生 PDF 阅读器，并增加 30 秒加载超时。依赖与 Worker 均由 Vite 构建为同源资源，不使用 CDN。

## 回答、耗时与处理过程

正文与中间过程使用 Markdown 渲染；新的 SSE 完整消息也标记为本轮新内容，首次挂载从空文本逐字呈现，而不是因事件名为 completed 就按历史直接显示。入场标记消费后不重复播放，历史与后台恢复仍立即显示。服务端结束和 open 快照刷新不能冲掉尚未播完的正文；过程在自身新文字呈现完成后才自动折叠。大段文字在已有动画帧排队期间到达时，同样重算追赶预算，避免挤在最后一帧全部显示。桌面与移动端使用相同逻辑。新增内容仍按字素依次推进，每个字以约 640ms 的淡入、轻微晕染过渡到清晰，相邻文字的过渡交叠，避免生硬跳出或整段同时淡入；长篇输出自适应追赶，已显示文字保留原动画进度，历史内容直接呈现，减少动画偏好下关闭晕染。支持标题、列表、表格、引用和代码块。禁止 HTML 执行、危险链接及模型 Markdown 图片自动加载。最终回答结束后，将 HTTP/HTTPS 网页链接美化为带图标的标签，尝试读取网页标题和站点图标；裸网址在失败时显示域名，自定义标签保留原文字，悬停可查看链接全文，新窗口安全打开。链接元信息读取沿用 contract-service-fe 的浏览器 CORS、无凭据和无 referrer 请求，每条回答最多 30 个链接、并发 3 个、5 秒超时、读取至 head 或最多 256 KiB，缓存最多 200 条。标题跨域不可读时仍尝试站点 `/favicon.ico`；图标由浏览器独立显示，不要求图标站点支持 CORS，不添加业务 Authorization 请求头；图标失败时保留箭头，标题缺失则回退域名/原文，不影响回答；流式正文和中间过程不启动探测。底部保留复制和时间，不显示分支按钮。

展示层沿用 contract-service-fe：除 thinking 外，仅原始过程顺序中相邻、类型一致且后端 message 逐字完全相同的通知复用首项（空格、标点和大小写均参与比较）；中间出现 thinking、过程输出或其他状态即打断合并，即使 thinking 不显示也不跨项合并。思考只显示当前活动项，不累积进历史。已结束状态将开头的“正在”改为“已”，过长说明使用省略号截断（有冒号时保留前缀，其后最多 15 个字符；无冒号时最多 15 个字符），悬停可查看全文；合并始终比较完整原文，不使用截断后的文字；原始 SSE 事件与说明保持不变。取消、方向替代和失败分别标注停止、中断或未完成。思考态沿用 contract-service-fe 的呼吸文字，联网检索和外部专家状态复用其 16px WebP 图标，结束后淡化并变灰；跨平台续聊 `task.progress.type=a2a` 使用 `a2a.webp`；广播求助使用后端约定拼写 `boardcast`，展示 `boardcast.webp` 和接口消息“正在广播求助”，历史 `a2a` 广播事件仍按原类型恢复。两者的动作消息与本地/联网搜索共用相邻去重、详情截断、状态文案和呼吸效果，实时事件、任务快照及历史回放采用相同规则；页面停用时暂停呼吸动画，减少动画偏好下静态显示。回答前的耗时区支持展开公开处理过程，过程来自真实 `task.progress` 和 intermediate 消息；不伪造检索步骤，也不展示模型内部轨迹。后端目前可能整段返回公开输出，前端动画只改善呈现，不代表底层逐 token 推理流。正文出现后过程可以折叠，用户可再次展开。耗时依据后端激活时间更新，结束后使用后端 `processing_duration_ms`。

SSE 的 delta 追加，completed 按消息 ID 覆盖；事件按游标去重。最终正文出现不代表任务结束，只有终态事件或任务快照确认完成后才解锁后续任务。历史优先恢复服务端 display 事件，同时读取 `display.streaming_messages` 中尚未收束消息的累计正文，再采用对应的 `last_sequence` 继续接收增量；该游标包含未列入 events 的 delta，不能只恢复事件而跳过累计片段。生成中刷新、身份复核和重新打开树时，前文与消息的 streaming 状态保持连续；完成或中断仍以服务端完整消息及任务终态为准。活动任务按服务端开始时间立即恢复计时，不等待下一秒定时刷新；终态耗时只使用服务端值。旧历史没有事件时只呈现已有公开消息，不合成中间过程。

探索允许从已结束的主干或分支任务继续，也允许从已有后继的分支节点再开分支；提交起点使用实际 selected_node_id，推进仍只允许主干末尾。后端 parent_id 与 path_type 是拓扑依据，前端 branchId 仅用于分列：分支的首个后继沿原列延伸，再从同一节点探索时分配独立列；嵌套分支遵循同一规则。实时登记与历史加载共用归列规则，避免回答生成期间重叠、刷新后变位。摘要保留实际父链，既有后继与 main_leaf_id 不因探索改变。

## 队列、停止与调整方向

不同问答树可以同时生成回答，任务提交、停止、提交结果待核对与队列按树隔离；同一棵树生成中再次发送将问题和附件加入本地队列，卡片悬浮在输入框上方。正常结束并刷新权威树后按序发送；同一位置的后续问题接续到新任务。切换树或阅读位置不改变已捕获的上下文、文件、强度与模式。队列和未发送草稿只保存在当前工作台内存中。未查看的树收到新的最终回答时，在下拉列表树名右侧显示小蓝点；thinking、工具状态和中间过程不触发提醒，重复 SSE 不重复触发。查看包含新回答的上下文路径后清除对应提醒；仅展开列表或查看其他分支不清除。当前路径可见时收到的最终回答直接视为已读，页面恢复可见时清除当前路径已查看的提醒。执行状态、最终回答基线、已读内容指纹和未读节点按 userid 隔离保存在浏览器 localStorage，最多 200 棵树、保留 30 天；不缓存问题、回答原文、附件或 token。刷新后先恢复提醒，再以接口核对；损坏、过期或不可用的缓存不阻塞使用。查看对应消息后记录已读指纹，避免刷新后重复提示；首次没有缓存时不将旧历史当新消息。

列表状态按后端 `has_running_task` 展示，仅表示请求时刻仍在执行的任务，不作为注册任务的执行锁；创建和改名响应仍只含 id/name。页面可见且问答页活动时，每次列表请求结束 5 秒后再次探测；隐藏/停用暂停并取消列表请求，返回时立即探测，无重叠请求。后台探测不显示列表 loading、不清除草稿或切换阅读节点；失败保留上次状态，间隔退避到 15/30 秒，成功恢复 5 秒；401 通知统一认证并暂停，身份重新验证后恢复。SSE 及时更新正在执行标记，较早发出的列表响应不能覆盖更新的 SSE 状态。

树条目右侧操作区固定 12px 状态槽位，位于改名按钮左侧，与改名、删除按钮按整行垂直居中对齐，进行中优先显示蓝色转圈，无进行任务但有未读最终回答时显示蓝点，两者中心对齐，空闲保留槽位避免跳动。遵循系统减少动画偏好。对未订阅的后台任务，首次探测到执行时按需读取树以建立最终消息基线；从执行变为结束后再核对最终消息，仅新增最终回答触发提醒，停止/失败/过期本身不触发。该列表没有最终消息游标，因此无法识别两次探测之间完整发生且从未被观察到执行的外部任务，不以猜测生成蓝点。

停止调用服务端 cancel，以返回快照为准，不在网络失败时假装停止。手动停止暂停队列，用户点击“立即发送”后继续。

“调整方向”仅对当前生成任务位置的排队问题启用，并遵守服务端可中断/已登记状态。前端提交 `supersedes_turn_id`，继承旧任务模式，不先 cancel；只有新任务登记成功才将旧任务标为被替代。登记失败保留旧任务和队列。

## 图片与附件预览

上传按钮位于输入框内左下，附件横排悬浮在输入框上边缘，进出采用滑动淡入与收缩动画；横向溢出不显示滚动条。输入框支持 Ctrl/Cmd + V 粘贴剪贴板图片及截图，复用文件选择的转换与校验流程；图片与文字混合粘贴时保留原生文字插入，不将 HTML、图片网址或本地路径转换为附件。仅接受支持的图片格式，客户端先转单页 PDF，再随任务上传，转换时锁定原草稿位置。图片转换不等同于后端已经保存，只有任务请求确认才清除草稿。

历史记录中的附件按单个文件卡片排列在对应用户消息上方，靠右对齐；PDF 显示文件图标、文件名及类型，长文件名省略但可悬停查看。点击本地或历史附件打开与 contract-service-fe 一致的玻璃遮罩 PDF 弹窗。历史附件通过带 Bearer 的 resource 请求下载为 Blob URL 后预览，不把鉴权 token 放入地址。当前弹窗支持 images 类型对应的 PDF；音视频显示暂不支持预览。请求失败显示具体错误，关闭取消未完成下载，退出用户工作台时释放所有 Blob URL。

## 移动端多选与置顶

问答树列表首个分组标题右侧提供多选入口。进入后以选择圆圈替代普通会话点击，顶部显示已选数量与退出按钮，底部操作栏替代账户区；顶部工具栏、底部账户区和多选操作栏采用渐变玻璃覆盖层，列表从其背后滚过时模糊淡出，文字与按钮保持清晰。进入多选时标题和关闭按钮在原搜索区域淡入，圆圈从左侧滑入，保持顶部占用高度一致；列表保留上下留白，首末条目均可滚动到完整可见区域。搜索、新建、长按菜单和下拉刷新暂时停用，列表仍可滚动。关闭抽屉、切换页面或返回桌面布局时清空多选，勾选不会打开或切换问答树；从左侧圆圈按下后可上下滑动连续选择，从未选圆圈起笔统一勾选、从已选圆圈起笔统一取消，折返不重复翻转；快速滑过的中间条目也会覆盖，靠近列表上下边缘时自动滚动继续涂选。从文字区域开始仍为正常滚动，横向移出选择列、触摸取消、退出多选或目录更新时结束本次手势，不撤回已完成的勾选；条目点击不增加选中底色，保留按钮按压回弹与键盘焦点提示。

置顶是当前浏览器的显示偏好，按 userid 仅保存树 ID，不调用后端、不跨设备同步。所选条目全部已置顶时提供取消置顶，否则统一置顶；置顶组位于时间分组之前，组内继续按真实更新时间排序。成功删除或新的真实目录不再包含该树时清理其置顶。存储受限时，本次访问仍可置顶并明确提示未保存。

批量删除先展示数量和不可撤销范围的确认弹窗，点击确认按钮后逐棵调用现有真实删除接口，不要求逐棵输入树名；每棵只有确认成功后才移除条目及其会话缓存。首个失败立即停止，显示服务端原始错误，保留失败和未处理的条目，用户重试仅处理未确认成功的部分。401 交给统一认证，不自动重放删除。后端已提交数据库删除、附件仍待清理的失败，允许用户按原 ID 重试清理，即使后续目录已不再包含该树；不把 404 或不确定结果伪装为成功。离开页面时不再启动后续删除，已经发出的请求仍以服务端结果为准。

## 对话关键词搜索

移动端问答树列表顶部的搜索框仅匹配本地缓存中的用户问题和最终回答，不搜索树名称、上下文摘要、中间过程、工具信息或附件。多个空白分隔的关键词需在同一任务的问题或回答中全部出现，忽略英文大小写和全半角差异；点击搜索框时，列表宽度、搜索框位置、返回与新建按钮及底部账户区连续过渡到全宽搜索模式；输入合并窗口内先展示条目骨架，最后一次输入后至少展示 0.5 秒再淡入本地结果，连续输入只处理最后一次关键词；清空或退出搜索时立即取消等待。减少动画偏好下关闭位移和骨架扫光。返回按钮退出并恢复列表，清空按钮保留输入焦点。结果显示对话图标、所属树、树更新时间及命中片段，关键词加粗；命中用户问题时在图标右下角叠加当前用户的小头像，命中最终回答时不显示头像。同一任务的问题和回答都命中时分别展示。点击结果读取真实树历史，再选中对应任务，恢复其上下文路径；节点已被替代或删除时提示重新搜索，不用缓存替代权威问答页面。

对话文本使用 IndexedDB 按 userid 和树 ID 隔离保存，与只保存指纹的未读状态缓存独立。成功获取真实目录后，按接口更新时间补齐或更新节点缓存，最多并行读取两棵树；打开树取得的快照同时更新缓存。搜索输入本身不发请求。目录中已移除的树清理缓存，版本过期的缓存不参与搜索；页面隐藏或停用时中止后台补齐，恢复后继续。切换用户销毁旧内存及请求，新用户只能读取自己的缓存。

搜索区域在首次补齐期间显示缓存进度；部分读取失败明确说明搜索范围不完整并允许重试。浏览器禁用存储或空间不足时使用本次访问的内存缓存并提示，真实接口失败不伪装成正常空结果。缓存不保存 token、附件文件或中间过程，清除浏览器站点数据后需要重新补齐。

## 恢复、身份和缓存

网络断开后按同一 turn ID、Last-Event-ID 游标重连，不重复 POST 问题。必要时先读取快照恢复公开消息，再继续订阅；断线与后台重连状态不展示顶部 hint 或“重新连接”按钮；保留已有的有限重试、目录轮询和页面恢复时的重连。连接状态与普通请求错误分开维护，目录、提交等实际请求失败仍展示错误与“重新加载”。404/410 或进程重启导致任务不可恢复时重新读取数据库历史并提示错误，不自动重新执行模型。

KeepAlive 停用时取消订阅及计时器，服务端任务继续执行；恢复页面读取快照并重连。切换用户销毁旧工作台，请求及附件资源随之释放。401 交由根认证流程处理；服务失败不清除 token，不显示为正常空数据。
