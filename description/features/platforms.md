# 管理平台入口

管理平台页提供平台选择、摘要、管理人列表与平台入口，入口为顶部“管理平台”。平台资料通过 `GET /knowledge-accumulation/api/platform/list` 读取 knowledge-accumulation-be 的[平台列表接口](../../../knowledge-accumulation-be/description/api/platform.md#查询平台列表)，不再使用模拟平台或人员。

## 布局与交互

页面参照 `registry-fe` 审核广场，保留两栏：左栏选择平台，右栏展示平台信息。左侧沿用审核类型导航的圆角表面、渐变滑块、状态点、悬停与入场动画；桌面左栏宽度约 224–254px，右栏占据剩余空间。详情内部再分两栏：左栏上方展示 Markdown，下方固定显示水平居中的进入按钮；右栏独立显示平台管理人。桌面详情不整体滚动，超长描述和多人列表分别在各自区域滚动，按钮始终可见。901px 及以上使用并排详情，761–900px 改为描述与管理人上下排列；760px 及以下改为上方两列选择按钮、下方详情，页面纵向滚动。

- 初始不选中平台，右栏展示从 `registry-fe` 复制的 `src/assets/sleep.webp` 及选择提示。
- 平台名称和 logo 仅在选择栏展示；右侧选择后从 `description` 摘要开始，不重复显示标题或图标，保留仅供辅助技术读取的平台标题，右侧按纵向列表显示 `admins` 中的姓名与圆形头像；再次点击当前平台取消选择。不再展示演示标识、虚构角色、功能标签或入口说明。
- 知识注册中心的“进入平台”复用项目基础路径 `import.meta.env.BASE_URL`，移除末尾斜杠后拼接 `/registry`，不另行判断环境。在当前窗口导航至开发路径 `/dev/knowledge-accumulation/registry`，生产构建使用 `/knowledge-accumulation/registry`，仅开发模式带 `/dev` 前缀。跳转沿用当前域名及共享的 `localStorage.access_token`，URL 不携带凭据。合同管理平台沿用相同规则拼接 `/contract`，开发路径为 `/dev/knowledge-accumulation/contract`，生产路径为 `/knowledge-accumulation/contract`，在当前窗口跳转。
- 管理页通过 `KeepAlive` 保留平台选择；各平台详情按 code 缓存，最多保留 12 份，切换或取消选择不重建已缓存详情及头像，刷新整个网页后重新加载。
- “进入平台”采用用户提供的 Uiverse.io / ke1221 浅灰浮雕按钮样式，按下时呈内凹阴影；跳转链接与未配置入口的禁用按钮保持统一外观。

## 平台描述 Markdown 契约

接口继续使用字符串字段 `description`，存放原始 Markdown；不需要新增格式字段，也不需要后端转换 HTML。推荐按“一句话摘要 → 核心功能 → 适用场景 → 关键词”编写，以下功能仅作格式示例，应替换为平台实际能力：

```md
围绕合同全生命周期，提供**集中管理、智能审查与知识复用**能力。

### 核心功能

- **合同归档**：统一管理合同文件，按项目、类型快速查找。
- **智能审查**：识别关键条款与潜在风险，辅助人工审核。
- **知识检索**：检索历史合同与相关条款，复用已有经验。

### 适用场景

合同审核、历史合同查询、条款比对及履约信息追溯。

### 关键词

`合同管理` `智能审查` `风险识别` `知识检索`
```

- 首段作为平台摘要，用略大的字号展示；`**功能名**` 用于突出价值和功能关键词。
- 用 `###` 分隔功能、场景与关键词，功能用列表表达，推荐 3–6 项。章节可省略，前端不自动生成缺失内容，也不依赖标题名称提取业务数据。
- 关键词使用独立的行内代码片段，例如 `` `合同管理` `智能审查` ``，统一渲染为随平台配色变化的圆角标签；标签只用于展示，不参与搜索、筛选。
- 支持段落、换行、标题、有序及无序列表、嵌套列表、加粗、斜体、行内代码和普通链接。描述标题从 h3 开始，四级及以下标题显示为 h4，平台名称仅供辅助技术通过隐藏的 h2 读取。
- 禁用原始 HTML、图片、脚本及自定义组件，不支持表格、代码块或 YAML 元信息。链接由解析器校验协议，不启用自动链接或额外插件。
- 现有纯文本描述直接展示并保留换行；空白描述显示“暂无平台摘要”。管理人、名称与入口仍由现有字段和组件负责。

`models/platformDescription.js` 使用 `markdown-it` 的最小语法预设及明确规则列表生成 HTML；`PlatformDescription.vue` 负责响应描述变化并统一排版。原始描述不直接传入 `v-html`，只渲染禁用 HTML 的解析器输出。样式局限在组件内，长文本与关键词可换行，小屏缩小字号和间距。

## 实现与边界

`PlatformNavigation.vue` 负责选择栏，`ManagementPlatforms.vue` 负责选择与详情缓存，`PlatformDetail.vue` 承载描述、进入按钮和管理员两栏内容，`usePlatforms.js` 负责加载状态和生命周期，`services/platforms.js` 集中处理认证请求、响应验证、75 秒超时与错误。首次进入管理页时加载，切换页保留数据和选择；身份重新确认后刷新，用户变更、失败和迟到响应不会继续展示旧用户目录。页面停用会取消未完成的目录请求，再次激活时补载；成功目录在普通页面往返时不重复加载。

`data/platformPresentation.js` 仅维护图标、配色及已确认的入口地址。后端合同平台代码为 `contract-pheno`，使用 `src/assets/contract.webp`；注册中心使用 `src/assets/registry.webp`。其他子平台使用通用图标，名称和摘要不从代码猜测。不按 `is_alive` 隐藏平台，也不将中间件存活状态作为访问权限或网页可达性。

头像复用 `UserAvatar.vue`，从 `admins[].avatar_url` 取得文件名，携带共享 token 调用头像接口；空头像或读取失败使用默认人像，取消和 Blob URL 清理见[用户头像](../platform/authentication.md#用户头像)。同名管理人保留独立列表项，不补造 userid、角色或部门。空管理员数组显示“暂无管理人”。

管理人条目由 `PlatformManager.vue` 承载：先在折叠状态加载头像，浏览器完成图片解码后，再展开列表高度并从右侧滑入、淡入。多人按索引错开 70ms，最大延迟 280ms；各条目独立就绪，不等待整组头像。无头像或读取、解码失败时用默认人像入场，切换平台或卸载时取消未执行的动画帧。系统减少动画偏好下直接显示，不做滑动过渡。资料未变化时保留已有头像，避免身份刷新造成反复闪现。

列表沿用接口可见范围与顺序，可包含注册中心自身。名称、Markdown 描述、存活状态及管理人均使用接口值；本地仅匹配图标、配色和已确认入口，不追加固定注册中心或本地摘要。空数组显示“暂无平台”，失败不展示伪造资料；后端实时读取目录与管理员数据库，不提供同步时间。

加载、真实空列表与请求失败分别处理；故障提供重试，不回退到 mock。401 通知统一入口重新确认登录，503 保留共享凭据。接口未提供跳转地址，其他平台入口仍需明确配置，不能由平台代码拼接；服务端鉴权与入口展示边界见[项目总览](../project.md#后端契约与接入边界)。

`npm test` 覆盖描述模板、纯文本兼容、标题层级、危险 HTML/链接及图片禁用，以及平台响应、Bearer 传递、401/503、取消与超时、身份变化和迟到请求；另需验证真实平台接口、管理人头像和页面选择交互。
